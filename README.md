## Traffic Sign Classification using CNN (PyTorch)

**Summary:**

*Model:* Custom CNN (2 Conv+ 2 FC)
*Dataset:* German Traffic Sign Recognition Benchmark(GTSRB)
*Input:* 32×32 RGB images
*Classes:* 43
*Test Accuracy:* 93.53%
*Inference:* Single-image prediction supported
*Built with:* PyTorch

Note: Train the model first by running python src/train.py to generate models/traffic_sign_cnn.pth.
